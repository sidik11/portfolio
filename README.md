# MD Sidik — Cyber-Punch Engineering Portfolio ⚡

A high-performance, punchy, cinematic dark developer portfolio engineered with obsidian tones, electric neon crimson accents, and glassmorphic HUD interfaces.

![Portfolio Live Spec](https://avatars.githubusercontent.com/u/149406522?v=4)

---

## ⚡ Highlights & Upgrades

- **Visual Architecture:** Deep stealth black palette (`#060508`) illuminated by neon crimson (`#ff2a44`) glows and ambient radial lighting.
- **Cyber HUD Spec:** Profile terminal, 3D holographic tilt effects, live status badge (`36+ Public Repos`), and scanline HUD badge.
- **Bento & Matrix Grid:** High-impact bento cards detailing systems engineering, education, and security architecture.
- **Interactive Skills Deck:** Live category filtering (Frontend, Backend, Database, DevOps) with animated skill meters.
- **Flagship Showcase:** Detailed case studies for **Competitive Exam Platform**, **Secure Image & Media Vault (AES-256)**, **Excel Catalog**, and **MS InnovateX**.
- **Interactive Live Terminal:** Simulating live shell commands, status flags, and development philosophy.
- **Performance:** 100% vanilla web stack (HTML5, modern CSS3 variables, zero heavy dependencies), silky smooth 60fps animations.

---

## 🛠️ Stack & Tooling

- **Core:** HTML5, CSS3 Custom Properties, Vanilla JavaScript (ESNext)
- **Typography:** *Plus Jakarta Sans* & *DM Mono* via Google Fonts
- **Interactivity:** IntersectionObserver API, RequestAnimationFrame cursor physics, 3D perspective tilt
- **Compatibility:** Fully responsive across mobile, tablet, laptop, and ultra-wide displays

---

## 🚀 Running Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/sidik11/portfolio.git
   ```
2. Open `index.html` in your favorite web browser or start a local server:
   ```bash
   npx serve .
   ```
