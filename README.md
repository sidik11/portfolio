# MD Sidik — Portfolio

A cinematic dark portfolio with a red-accent visual system, built as an original implementation inspired by the visual language of the uploaded Reel.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- IntersectionObserver reveal animations

## Content
Content is based on public information from github.com/sidik11 and selected public repositories:
- Competitive Exam Master
- MS InnovateX
- Excel & Image Vault
- MS Gallery
- Chunk

## Run
Open index.html or serve the folder with any static server.

## GitHub Pages
This is a static site and can be deployed directly with GitHub Pages.
